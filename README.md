# PAYNET — 연봉·세금·부동산 계산기

세전 연봉·시급·부동산 비용을 입력하면 **예상 실수령액·세금·중개수수료·양도세·대출이자**를 바로 확인할 수 있는 웹 계산기입니다.

HTML, CSS, JavaScript만으로 구성되며, 별도 빌드나 서버 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

### 급여·세금
- **실수령액** — 세전 연봉 기준 월/연 실수령액, 공제 내역
- **근로소득세** — 과세표준, 공제액, 실효세율
- **4대보험** — 근로자/회사 부담 구분
- **시급계산기** — 시급 ↔ 월급 환산 (주휴수당 옵션, 월 209시간 기준)
- 부양가족 수, 월 비과세액 반영
- 금액 입력 시 천 단위 콤마 자동 포맷

### 부동산
- **중개수수료** — 매매/임대차, 주택·주택 외, 법정 상한 요율 + 부가세
- **양도소득세** — 양도·취득·필요경비, 보유기간, 1주택 비과세 가정 (참고용)
- **대출이자** — 원리금균등 / 원금균등 / 만기일시상환

### 콘텐츠·정책 페이지
- 급여·세금 가이드 모음 (`guides.html` 및 개별 가이드)
- 소개, 이용약관, 개인정보처리방침, 문의

## 실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.

```bash
# 예: Windows
start index.html
```

별도 설치나 `npm` 실행은 필요하지 않습니다.

## 사용 방법

1. 상단에서 **급여·세금** 또는 **부동산** 카테고리를 선택합니다.
2. 원하는 계산기 탭을 고릅니다.
3. 금액을 입력하면 결과가 즉시 갱신됩니다.

| 카테고리 | 탭 |
| --- | --- |
| 급여·세금 | 실수령액, 근로소득세, 4대보험, 시급계산기 |
| 부동산 | 중개수수료, 양도소득세, 대출이자 |

## 계산 기준 (참고)

`script.js`는 **2025년 요율·일반 가정을 반영한 예상 계산**입니다. 실제 급여·세무·부동산 비용과 다를 수 있습니다.

### 급여·4대보험·소득세

| 항목 | 요율 / 기준 |
| --- | --- |
| 국민연금 | 4.5% (월 기준소득월액 상한 6,370,000원) |
| 건강보험 | 3.545% |
| 장기요양 | 건강보험료의 12.95% |
| 고용보험 | 근로자 0.9% (회사 부담은 대략치) |
| 소득세 | 근로소득공제·인적공제 반영 후 누진세율 |
| 지방소득세 | 소득세의 10% |

### 부동산

| 계산기 | 기준 |
| --- | --- |
| 중개수수료 | 주택 매매/임대차 법정 상한 요율, 주택 외는 0.9% 참고 |
| 양도소득세 | 양도차익 − 장기보유특별공제(단순화) − 기본공제 후 누진세율 참고 |
| 대출이자 | 원리금균등 / 원금균등 / 만기일시(이자만) 단순 계산 |

> 고가주택·중과·거주기간·협의 수수료·변동금리 등은 모두 반영하지 않습니다. **법적·세무 자문이 아니며 참고용**입니다.
