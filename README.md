# PAYNET — 연봉 실수령액 계산기

세전 연봉을 입력하면 4대보험·소득세·지방소득세를 반영한 **예상 실수령액**을 바로 확인할 수 있는 웹 계산기입니다.

HTML, CSS, JavaScript만으로 구성되며, 별도 빌드나 서버 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

- 세전 연봉 입력 시 월/연 실수령액 즉시 계산
- 부양가족 수(본인 포함), 월 비과세액 반영
- 공제 내역 상세 표시
  - 국민연금
  - 건강보험
  - 장기요양보험
  - 고용보험
  - 소득세
  - 지방소득세
- 금액 입력 시 천 단위 콤마 자동 포맷

## 실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.

```bash
# 예: Windows
start index.html
```

별도 설치나 `npm` 실행은 필요하지 않습니다.

## 프로젝트 구조

```
calculator/
```

## 계산 기준

`script.js`는 **2025년 요율**을 기준으로 한 예상 계산입니다.

| 항목 | 요율 / 기준 |
| --- | --- |
| 국민연금 | 4.5% (월 기준소득월액 상한 6,370,000원) |
| 건강보험 | 3.545% |
| 장기요양 | 건강보험료의 12.95% |
| 고용보험 | 0.9% |
| 소득세 | 근로소득공제·인적공제 반영 후 누진세율 |
| 지방소득세 | 소득세의 10% |

> 회사·지역·추가 공제 항목에 따라 실제 실수령액과 다를 수 있습니다. 참고용으로 사용해 주세요.

## 사용 방법

1. **세전 연봉**을 입력합니다. (기본값: 40,000,000원)
2. 필요하면 **부양가족 수**, **월 비과세액**을 조정합니다.
3. 화면에서 월 실수령액, 연 실수령액, 공제 상세를 확인합니다.
